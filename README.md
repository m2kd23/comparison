# H-Compare (신·구조문대비표 자동 생성기)

HWPX 형식의 아래한글 규정 문서를 업로드하면, 개정안과 현행안을 어절 수준으로 비교·대조하여 **대한민국 법제처 표준 규격의 신·구조문대비표**를 화면에 렌더링하고, 레이아웃 깨짐 없이 한컴오피스 한글 문서(`.hwpx`) 파일로 완벽하게 다운로드해주는 웹 어플리케이션입니다.

서버로 파일을 전송하지 않고 사용자의 브라우저 상에서 모든 파싱과 대조가 100% 클라이언트 사이드로 진행되므로, 기관 내부의 기밀 규정 문서도 외부 유출 우려 없이 안전하게 비교할 수 있습니다.

---

## 🌟 핵심 제공 기능

### 1. 표(Table) 구조적 대조 및 축소 표시 (Cell-by-Cell Diff)
* 표의 격자 구조(테두리선, Cell Row/ColSpan)를 완벽히 해석하여 보존합니다.
* 구조가 동일한 표는 전체를 통째로 교체하는 대신, **각 셀 내부의 변경된 텍스트만 단어 수준으로 비교(LCS)**하여 하이라이팅합니다.
* 별지 서식 등의 첫 줄에 있는 테두리 없는 제목 행을 감지하여 한글 본래 레이아웃대로 렌더링합니다.

### 2. 동적 법령명 서브타이틀 추출
* 업로드한 파일명(예: `한국광해광업공단 임직원 행동강령(2026년 정정).hwpx`)을 스스로 분석하여 불필요한 수식어를 클렌징하고 법령명을 치환합니다.
* 파일명이 단순한 형태(`현행안.hwpx`)인 경우 본문 내용 중 법령명 접미사(`법`, `령`, `규칙`, `강령` 등)로 끝나는 최빈 단락을 자동 감지하여 화면 서브타이틀 및 다운로드 한글 파일 제목에 동적으로 반영합니다.

### 3. 양방향 어절 수준 LCS Diff 엔진
* 표준 적색/청색 표기법을 준수합니다.
* **현행안(좌측)**의 삭제된 문구는 **빨간색 취소선**으로, **개정안(우측)**의 새로 추가된 문구는 **파란색 글씨**로 정교하게 매핑하여 가독성을 극대화합니다.

### 4. 미변경(생략) 범위 요약 처리
* 내용의 변화가 없는 조항들은 대비표 상에 일일이 나열하지 않고 `①ㆍ② (생  략)` / `(현행과 같음)` 범위로 축약하여 스크롤 길이를 줄이고 변경점이 있는 조항에만 집중할 수 있도록 돕습니다.

### 5. 별지 및 별표 서식 독립 노드화 (Annex Detection)
* 문서 하단의 `[별표 1]`, `[별지 제1호 서식]` 등의 서식 제목을 감지해 일반 조항에 종속되지 않고 독립적인 대조 행으로 파싱하여 정렬합니다.

### 6. 서식 하단 정렬 보완 및 서명 이중화
* 날짜(`년 월 일`), 제출처(`귀하`) 등의 가운데/우측 정렬을 완벽 재현합니다.
* `신고인 (서명 또는 인)`과 같이 이름(좌측)과 서명(우측)이 분리된 레이아웃을 웹에서는 **Flexbox**로, 한글 문서 다운로드 시에는 호환성을 고려하여 **투명 테이블(Nested Table)**로 이중 변환하여 내보냅니다.

### 7. 한컴오피스 최적화 OLE HTML 변환 내보내기
* **용지 여백 보존:** A4 양옆 여백 20mm 규격을 강제하여 인쇄 및 편집 영역을 고정합니다.
* **오버플로우 방지:** 표 너비 `table-layout: fixed; width: 100%; word-break: break-all;` 처리를 통해 우측 개정안 열이 찌그러지거나 잘리는 현상을 방지합니다.
* **배경색 오류 우회:** 한컴오피스가 투명 배경(`transparent`)을 검은색 오버레이로 오인하여 글자가 안 보이게 칠해버리는 OLE 호환성 버그를 우회하여 흰색 배경을 강제 처리하였습니다.
* **인라인 스타일 변환:** 복잡한 CSS 선택자를 해석하지 못하는 한글 OLE 파서를 우회하기 위해, 다운로드 시 모든 요소를 인라인 스타일로 자동 치환하고 표 안의 표(중첩 표)는 **8pt**의 최적화된 글자 크기로 변환합니다.

## 🚀 사용법 및 GitHub Pages 배포

### 로컬 실행 방법
1. 저장소를 클론하거나 다운로드합니다.
2. `comparison/index.html` 파일을 웹 브라우저에서 직접 더블 클릭하여 실행합니다.

### GitHub Pages 배포 방법 (웹 호스팅)
1. GitHub 저장소의 `Settings` -> `Pages` 탭으로 이동합니다.
2. **Build and deployment**의 Source를 `Deploy from a branch`로 설정합니다.
3. Branch를 `main` (또는 `master`) / `/ (root)` 로 지정한 뒤 **Save**를 누릅니다.
4. 잠시 후 `https://<GitHub-Username>.github.io/<Repository-Name>/` 주소로 접속하면 즉시 실행 가능한 비교 서비스 페이지가 공개됩니다.
